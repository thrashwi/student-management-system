# StudentHub – Student Management System

StudentHub is a web-based **Student Management System** designed to help educational institutions manage student information through a clean and professional dashboard.

The system provides student management, course information, attendance tracking, statistics, and a responsive dashboard interface.

## Features

* Professional dashboard
* Student registration and management
* Add, edit, search, and delete students
* Student attendance tracking
* Student status management

  * Active
  * Inactive
  * Graduated
* Course management
* Course-wise student distribution
* Attendance overview
* Student statistics
* Recent student records
* Search and course filtering
* Dark/Light mode
* Responsive design
* Local Storage data management
* Git and GitHub version control

## Dashboard

The dashboard displays:

* Total Students
* Active Students
* Graduated Students
* Average Attendance
* Recent Students
* Course Distribution
* Attendance Overview
* Quick Actions
* System Status

## Technologies Used

* **HTML5** – Web page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application functionality
* **Local Storage** – Client-side student data storage
* **Git** – Version control
* **GitHub** – Remote repository and collaboration


## Student Management

The Students section allows users to:

1. View all students
2. Search students
3. Filter students by course
4. Add new students
5. Edit student information
6. Delete student records
7. View attendance
8. View student status

## Data Storage

Student information is stored using the browser's **Local Storage**.

This allows the application to maintain student data without requiring a backend database.
